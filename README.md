# Architecting the Enterprise AI Control Plane

Companion materials for the book by Palash Kanti Sen.

This project provides a reference implementation showing how an agent prepares a service request, obtains human approval and calls a business-system API.

The example covers agent permissions, controlled actions, duplicate prevention and audit records. Local tests use simulated external identity, policy and model services. AWS, Azure and hybrid deployment files are supplied as reference configurations.

As organisations adopt artificial intelligence, a new challenge emerges. How do they know which AI agents are operating across the enterprise, what information they can access, what actions they can perform, and how to stop them when something goes wrong?
Architecting the Enterprise AI Control Plane by Palash Kanti Sen addresses this challenge through an architecture that places governance, security and operational controls outside the AI itself.
The book follows Harbour Services, a fictional organisation, as it introduces copilots, AI assistants, autonomous agents and AI capabilities embedded within existing business applications. Through everyday business scenarios, readers explore how to:
Discover AI agents and identify unregistered or unauthorised AI activity.
Build AI registries and automate the collection of runtime information.
Manage agent identities, permissions and delegated authority.
Govern child agents and multi-agent workflows.
Control access to AI models, enterprise data, tools and business systems.
Enforce security policies and human approvals independently of the AI.
Monitor agent behaviour, revoke permissions and contain unwanted activity.
With 54 architecture diagrams, the book connects logical architecture to physical infrastructure and explores implementation across AWS, Microsoft Azure, Google Cloud, Akamai, on-premises and hybrid environments.
A worked reference implementation and downloadable companion code help readers move beyond theory. Deployment instructions, configuration examples, security tests and architecture walkthroughs demonstrate how the individual components work together to form an enterprise AI control plane.
The book also examines the limitations of agent discovery and governance, particularly when AI operates within third-party platforms outside an organisation's direct control.
Written for enterprise architects, solution architects, security professionals, platform engineers and technology leaders, this book provides a practical approach to adopting AI at scale without surrendering control of enterprise systems, data or business operations.
